# Gender Reveal

A simple, animated gender reveal invite with cute teddy bear vectors, event details, ultrasound upload, gift ideas, and RSVP.

## Event

- **Where:** McDonald's Marcos Highway  
- **When:** December 13, 2026 · 1:00 PM – 2:30 PM  
- **Dress code:** Pink for girl · Blue for boy  

## Open the site

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 5173
```

Then visit [http://localhost:5173](http://localhost:5173).
